# SidewallMath

Free tire size calculator. Type two sizes (265/70R17 vs 285/70R17) to see the % change, true speed, ride height, and sizes that fit your wheel. No signup.

**Live site: [https://matt5516.github.io/tire-size-calc/](https://matt5516.github.io/tire-size-calc/)** (free, no signup, runs in your browser)

## Tools
- [Tire size calculator](https://matt5516.github.io/tire-size-calc/tire-size-calculator/): Type two sizes. Get the verdict first: % taller, true speed, ride height, then the full comparison and a to-scale drawing.
- [Tire size converter (metric to inches)](https://matt5516.github.io/tire-size-calc/tire-size-converter/): 265/70R17 in inches, or what metric sizes make a 33 inch tire.

- [Speedometer calculator](https://matt5516.github.io/tire-size-calc/speedometer-calculator/): How wrong your speedometer and odometer get with new tires, or check it against GPS.
- [Gear ratio calculator](https://matt5516.github.io/tire-size-calc/gear-ratio-calculator/): Regear for bigger tires: ratio to restore stock, nearest common ratio, engine RPM at cruise.
- [Wheel offset calculator](https://matt5516.github.io/tire-size-calc/wheel-offset-calculator/): Backspacing and offset: how far a new wheel moves in toward the suspension and out toward the fender.
- [Tire date code reader](https://matt5516.github.io/tire-size-calc/tire-date-code/): Read the week and year a tire was made from its DOT code.

## Data sources
Tire dimensions follow standard geometry: sidewall height = section width × aspect ratio, overall diameter = wheel diameter + 2 × sidewall, circumference = π × diameter, revolutions per mile = 63,360 ÷ circumference. True speed, gearing and RPM formulas are the usual ratios of tire diameters. The ±3% diameter rule of thumb is quoted by Discount Tire's tire size calculator (discounttire.com/learn/tire-size-calculator) and 1010tires (1010tires.com/Tools/Tire-Size-Calculator). Speed rating symbols follow Discount Tire's speed rating page and the load index table follows the standard published index table; the date code layout follows Continental's DOT code guide. Sizes in the finder and converter are calculated, not tires on sale. Real tires vary by brand and model.

## About this repo
Static HTML, CSS and JavaScript on GitHub Pages. No ads, no cookies. The math lives in `assets/calc.js`. Corrections: [open an issue](https://github.com/Matt5516/tire-size-calc/issues).

Sizes are calculated from the numbers on the sidewall. Real tires vary by brand and model, so confirm fit, load index and speed rating for your vehicle.
